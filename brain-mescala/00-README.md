# Mescala Brain Vault

Abra este diretório como um novo cofre no Obsidian.

## Comece por aqui

## Como usar
O vault é a fonte de verdade conceitual do Mescala. Pastas ajudam na organização, mas as relações reais são expressas por `[[wikilinks]]`, MOCs e referências entre domínio, regras, fluxos, dados e arquitetura.

## Regra para agentes
Antes de alterar código:
1. leia [[00-MOC-MESCALA]];
2. leia [[03-DOMINIO]];
3. leia [[05-REGRAS-DE-NEGOCIO]];
4. leia o módulo/fluxo envolvido;
5. não invente regras ausentes;
6. confira [[decisoes/PENDENCIAS]]: o que está marcado como aberto ali ainda não foi decidido; os itens decididos apontam para a nota da decisão em `/decisoes`.

O app legado não é fonte de regra (e, segundo o PO em 2026-10-22, não tem uso real): veja [[tecnico/LEGADO-ATUAL]].
