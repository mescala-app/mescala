# /vault-brain

Crie ou atualize o vault Obsidian do projeto atual como cérebro do sistema.

Requisitos obrigatórios:
- fonte de verdade orientada a domínio;
- wikilinks `[[...]]` entre notas relacionadas;
- backlinks naturais por relações bidirecionais de contexto;
- MOCs para áreas centrais;
- frontmatter útil;
- regras, fluxos, módulos, dados, segurança, produto, técnico e decisões conectados;
- não inventar regras: marcar lacunas como **A DEFINIR**;
- manter CHANGELOG;
- entregar `.zip` pronto para importar/abrir no Obsidian.

Antes de alterar qualquer código com base no vault, leia [[00-MOC-MESCALA]], [[03-DOMINIO]] e [[05-REGRAS-DE-NEGOCIO]].
