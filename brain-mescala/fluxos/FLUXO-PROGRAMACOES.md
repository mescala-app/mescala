# Fluxo — Programações
1. Usuário autorizado cria [[modulos/PROGRAMACOES|Programação]].
2. Define data e intervalo de horário.
3. Vincula ministérios participantes.
4. Cada ministério pode gerar uma [[modulos/ESCALAS|Escala]].

## Decisões
- **Passo 1:** Culto é uma programação comum; Agenda é consulta das programações, sem tabela ([[decisoes/DEC-09-MODELO-DE-DADOS#DATA-DEC-003 — Programação × Culto × Reunião × Comissão × Agenda × Cronograma|DATA-DEC-003]]).
- **Passo 2:** a programação é uma ocorrência datada, com início e fim, sem recorrência nesta fundação ([[decisoes/DEC-09-MODELO-DE-DADOS#DATA-DEC-004 — Programações recorrentes|DATA-DEC-004]]).

## Pendências
- Quem é o "usuário autorizado": **A DEFINIR** ([[decisoes/PENDENCIAS#Outras pendências registradas|PENDENCIAS]]).
- Cancelamento de programação: nada decidido; **A DEFINIR**, se o tema aparecer ([[decisoes/PENDENCIAS#Cancelamento de Programação|PENDENCIAS]]).
- Reunião, Comissão, Cronograma e Pauta: fora do modelo até serem documentados ([[produto/CONCEITOS-DO-CANVAS]]).
